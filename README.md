# iPOP Gourmet Popcorn - Shopify Theme

Official Shopify theme for iPOP Gourmet Popcorn fundraising platform.

## Theme Structure

- **layout/** - Main theme layout (theme.liquid)
- **templates/** - Page templates (index, pages, collections)
- **sections/** - Reusable sections (header, footer, homepage)
- **assets/** - CSS, JavaScript, images
- **snippets/** - Reusable components
- **config/** - Theme settings and configuration
- **locales/** - Translation files

## Features

- Complete fundraiser signup and display flow
- Product catalog with fundraiser attribution tracking
- Mobile-responsive design
- Integrated cart system with Shopify Ajax API
- SEO optimized

## Installation

This theme is designed to be connected via GitHub integration in Shopify.

### Connect to Shopify

1. Go to Shopify Admin → Online Store → Themes
2. Click "Add theme" → "Connect from GitHub"
3. Select this repository and branch
4. Click "Connect"

### After Installation

Create these pages in Shopify Admin:
1. **Start a Fundraiser** page (template: `page.start-fundraiser`)
2. **Fundraiser** page (template: `page.fundraiser`)
