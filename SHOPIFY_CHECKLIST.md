# Shopify Migration Quick Checklist

## Phase 1: Preparation (Do This First)

### Product Data
- [ ] Create spreadsheet with all 12 products
- [ ] Write product descriptions (✅ already have these)
- [ ] Create unique SKUs for all variants (24 total: 12 flavors × 2 sizes)
- [ ] Organize all 12 product images in one folder
- [ ] Optimize images (under 2MB each, 2048x2048px recommended)
- [ ] Determine product weights for shipping

### Business Information
- [ ] Collect business license/tax ID
- [ ] Prepare bank account info for payments
- [ ] Write return/refund policy
- [ ] Write privacy policy
- [ ] Write terms of service
- [ ] Document shipping zones and rates

### Content
- [ ] Copy text from all pages (index, about, contact, etc.)
- [ ] Save logo and brand assets
- [ ] List all current URLs for redirects

## Phase 2: Shopify Setup

### Account Setup
- [ ] Sign up for Shopify (3-day free trial)
- [ ] Choose and purchase Shopify plan ($39/month Basic recommended)
- [ ] Set up store name
- [ ] Add business address

### Store Settings
- [ ] Configure tax settings (9.25% for Tennessee)
- [ ] Set up payment gateway (Shopify Payments recommended)
- [ ] Configure shipping zones and rates
- [ ] Set up email notifications
- [ ] Add policies (returns, privacy, terms)

### Theme Selection
- [ ] Browse Shopify theme store
- [ ] Choose theme (Dawn, Sense, or Studio - free options)
- [ ] Customize colors to match brand (Red #E63946, Yellow #FFD700)
- [ ] Upload logo

## Quick Cost Breakdown

**Recurring:**
- Shopify Basic: $39/month
- Transaction fees: 2.9% + 30¢ per sale
- Apps (optional): $0-50/month

**One-Time:**
- Domain: $15/year
- Premium theme (optional): $100-350
- Product photography (optional): $500+

**Minimum to get started: ~$55** (first month + domain)

## Red Flags (When NOT to Use Shopify)

❌ **Don't use Shopify if:**
- You can't afford $40+/month ongoing costs
- You only take phone/in-person orders
- You don't want to accept online payments
- Your products require complex customization
- You need heavy fundraiser program integration (may need custom solution)

✅ **Shopify is great if:**
- You want professional e-commerce
- You want to accept credit cards online
- You want mobile-friendly shopping
- You want automated order processing
- You want to scale your business
- You want detailed analytics
